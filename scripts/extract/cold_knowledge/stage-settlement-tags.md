## 玩家提问

副本通关结算时左边显示的“极速”、“应手”、“驭宠大师”等通关标签的触发条件分别是什么？为什么我脱了全部装备打主线副本，还是拿不到“赤膊上阵”这个标签？

## 核心机制

- **通关标签的性质**：
  通关标签是对玩家在单局副本中战斗表现的即时评价，与游戏成就无关。

- **全标签判定条件一览表**：

| 通关标签     | 获取判定条件                                      |
|:-------- |:------------------------------------------- |
| **斩妖除魔** | 成功通关/战斗胜利                                   |
| **极速**   | 通关时间小于 $180$ 秒（即 $3$ 分钟内）                   |
| **骑术高手** | 单局战斗中坐骑使用次数不少于 $2$ 次                        |
| **驭宠大师** | 全程只出战过 $1$ 只宠物，且宠物 $0$ 次阵亡                  |
| **法宝道人** | 法宝使用次数不少于 $10$ 次                            |
| **应手**   | 通关结算时人物血量不低于 $80\%$                         |
| **傲视三界** | 单局达到过较高的连击条件（最高连击数 $> 1$）                   |
| **赤膊上阵** | 全程未穿戴**任何**装备，且战斗中没有发生换装(事实上**无法打出**,解释见下方) |
| **不死之王** | 战斗中复活次数大于 $5$ 次                             |
| **佛系通关** | 全程未使用任何技能，且普通攻击次数 $> 0$                     |
| **闪转腾挪** | 战斗中受击次数小于 $1$ 次（即无伤通关）                      |
| **专精大师** | 全程只使用过 $1$ 种技能，且没有使用普攻                      |
| **时间旅行** | 单局通关时间超过 $1800$ 秒（即 $30$ 分钟）                |
| **多宝道人** | 人物/法宝主控切换不少于 $5$ 次，且法宝使用不少于 $5$ 次           |
| **宠物之家** | 单局使用超过 $3$ 只宠物（即至少使用 $4$ 只宠物）               |
| **刮痧大师** | 任意一个 Boss 战交战时长超过 $900$ 秒（即 $15$ 分钟）        |
| **不屑一顾** | 关卡中掉落了紫装，但一件都没有捡起并通关                        |
| **无欲无求** | 无活力通关                                       |
| **不灭**   | 全局 $0$ 次死亡，全程无复活                            |
| **极·噩梦** | 噩梦关卡在 $240$ 秒内（即 $4$ 分钟内）通关                 |
| **极·幻境** | 幻境关卡在 $600$ 秒内（即 $10$ 分钟内）通关                |
| **生·组队** | 组队状态下通关，且己方阵营无人死亡                           |
| **固·昆仑** | 守护类关卡通关时，守护目标（阵眼）血量保持 $100\%$               |

- 事实上**赤膊上阵**在正常游戏中根本**无法触发**.该标签判定要求玩家身上未发生任何换装且未穿戴装备。然而，游戏角色默认存在一套白色无属性装备(即家传套装)且无法卸下,但是系统依然将其计算为“已装备”，这就导致玩家即使手动脱下了所有装备，“赤膊上阵”标签依然无法触发

## 报告校验片段

- 通关结算时左边竖着显示的那些字，属于“通关标签”。
- `赤膊上阵` 在当前版本主线环境里，疑似是正常玩家拿不到的标签

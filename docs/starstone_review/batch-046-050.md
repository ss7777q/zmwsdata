# 星石效果复核 046-050

## 范围

- 046 武艺：守御；武曲星池；连续释放不同基础技能获得韧性，极效同规则获得闪避。
- 047 以攻为守：守御；武曲星池；普通效果是攻击转防御并扣减攻击，极效额外提高转入防御的比例。
- 048 以守为攻：攻伐；武曲星池；普通效果是防御转攻击并扣减防御，极效额外提高转入攻击的比例。
- 049 拆招：未知；未知；当前缺星石归属链路，多数普通等级缺 beskill，仅保留已配置等级与 warning。
- 050 体术：攻伐；武曲星池；普攻/跳攻释放前提高攻击，极效同条件提高暴击。

## 证据摘要

- 普通效果：46、50 保留 Lv.1-Lv.40 的 buff 成长；47、48 按 Lv.1 起就存在的双 skillId 解释为普通转换本体，分别展示目标属性增加与源属性扣减；49 只按已存在的 50048001、50048010 展示，其他普通技能缺失保持 warning。
- 极效：46、50 的 Lv.10/Lv.20/Lv.30/Lv.40 都实际引用同一个极效技能，分别为 50045501、50049501；47、48 的真正极效是从 Lv.10 起新增的 50046501、50047501，普通转换扣减项不是极效；49 的四档极效都引用 50048501。
- 运行时：检查 `releaseNoSameSkillDeal`、`getPropBasePerAndVal`、`sameSkillHurtCountDamage`、`preReleaseAtk` 与 `buff` handler。`releaseNoSameSkillDeal` 记录最近 4 次基础技能并按连续相邻不重复步数调层；`getPropBasePerAndVal` 在属性读取时返回基础属性乘配置比例；`sameSkillHurtCountDamage` 按受击技能配置 id 记录重复技能伤害；`preReleaseAtk` 在普攻/跳攻实际释放前触发。
- 归属：46、47、48、50 经 `starHavocPond -> dropGroup -> drop -> item -> starStone -> affixRandom` 命中武曲星池；49 未命中可验证 `starStone.affixRandom` 与星池掉落链。

## 覆盖与警告

- overrides：新增 046-050 的机制解释、summary、效果名、review 证据；46、50 保留未引用更高极效配置 warning；49 保留未知归属与缺失普通技能 warning。
- extractor：修正普通/极效切分，按 Lv.1 的 `skillId` 数量识别普通技能数量；新增 `addBuffIds` 关联 buff 解析；新增 `propName/propPer` 的属性转换数值展示；缺失普通/极效技能配置会合并为 warning。

# 星石效果复核 051-055

## 范围

- 051 寸劲：攻伐；武曲星池；近身攻击造成伤害时提高本次伤害，极效同近身条件提高暴击。
- 052 架势：守御；武曲星池；受到近身攻击时降低本次伤害，极效同近身受击条件提高韧性。
- 053 律令·疾：守御；廉贞星池；按技能1→技能2→技能3顺序释放后获得移速强化，极效同条件获得位移效率提升。
- 054 律令·愈：攻伐；廉贞星池；按技能1→技能3→技能3顺序释放后获得回魔强化，极效同条件返还最后一次技能蓝耗。
- 055 律令·甲：守御；廉贞星池；按技能2→技能3→技能4顺序释放后获得减伤，极效同条件获得护盾。

## 证据摘要

- 普通效果：51、52 保留 Lv.1-Lv.40 的近身增伤/近身受击减伤成长；53、54、55 保留 Lv.1-Lv.40 的 buff 成长，分别为 5 秒移速强化、5 秒回魔强化、5 秒减伤。
- 极效：51、52 的 Lv.10/Lv.20/Lv.30/Lv.40 都实际引用同一个极效技能，分别为 50050501、50051501；53、54、55 的四档极效分别引用 50052501-50052504、50053501-50053504、50054501-50054504。
- 运行时：检查 `addDamage`、`valueAddWithBeskillLv`、`skillReleaseQueueDeal`、`preAtkAndSkillAll` 触发入口。`skillReleaseQueueDeal` 记录最近最多 6 次释放编号，末尾匹配配置队列后触发、进入冷却并给自己加 buff；54 的 `backMp` 返蓝取 `min(最大蓝量比例上限, 最后一次匹配技能耗蓝比例)`。
- 归属：51、52 经 `starHavocPond -> dropGroup -> drop -> item -> starStone -> affixRandom` 命中武曲星池；53、54、55 命中廉贞星池。

## 覆盖与警告

- overrides：新增 051-055 的机制解释、summary、效果名、review 证据；51、52 保留未引用更高极效配置 warning。
- extractor：新增 `attribute.buffIds` 关联 buff 解析；新增对象型 `buff.value.per` 展示；新增 `backMp` 返蓝展示；新增 type=13 护盾 `value[3]` 的自身最大生命比例展示。

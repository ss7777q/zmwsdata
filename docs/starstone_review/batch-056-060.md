# 星石效果复核 056-060

## 范围

- 056 律令·木：攻伐；廉贞星池；按技能3→技能2→技能4顺序释放后，5秒内攻击附加木属性伤害，极效同条件获得木伤提升。
- 057 律令·剑：攻伐；廉贞星池；按技能3→普攻→普攻→普攻顺序释放后获得穿透提升，极效同条件获得吸血。
- 058 律令·雷：攻伐；廉贞星池；按技能1→技能4→普攻→普攻→普攻顺序释放后，5秒内攻击附加雷属性伤害，极效同条件释放跟随落雷。
- 059 律令·宠：攻伐；廉贞星池；按技能4→技能2→技能2→普攻顺序释放后生成防御降低光环，极效同条件生成召唤物伤害提升光环。
- 060 占位：未知；未知；仅占位配置，无可验证战斗效果、分类或星池归属。

## 证据摘要

- 普通效果：56、58 通过 `beskillIds` 触发二级 `addResistDamage`，保留 Lv.1-Lv.40，分别为木/雷属性附加伤害 0.25% 到 10.08%；57 保留 Lv.1-Lv.40 的 5 秒穿透提升，2.77% 到 110.61%；59 保留 Lv.1-Lv.40 的 15 秒防御降低光环，0.59% 到 23.76%；60 只有 Lv.1 占位行。
- 极效：56 引用 `50055501-50055504`，5 秒木伤提升 1.26%/2.52%/3.78%/5.04%；57 引用 `50056501-50056504`，5 秒吸血 0.24%/0.49%/0.73%/0.98%；58 引用 `50057501-50057504`，释放 `97003510101-97003510104` 跟随落雷；59 引用 `50058501-50058504`，用 `useLv=1-4` 生成召唤物增伤光环。
- 运行时：检查 `preAtkAndSkillAll`、`skillReleaseQueueDeal`、`addResistDamage`。普攻前记录 `-1`，技能释放前记录技能栏编号；`skillReleaseQueueDeal` 保留最近最多 6 次记录，末尾匹配队列后进入冷却并执行 `buffIds`、`vskillIds` 或 `beskillIds`。
- 虚拟技能：58 的 `mId=9700351`、`skill6_2` 生成 `bullet 400051`，`maxTime=5`、`hitInteval=0.5`；四档 skillLevel 为攻击力 4.41%/8.82%/13.23%/17.64% + 1。59 的 `skill7_1` 生成 15 秒防御降低光环，范围 `x=-400,y=-10,w=800,h=200`；`skill7_2` 生成同范围召唤物伤害提升光环。
- 归属：56-59 经 `starHavocPond -> dropGroup -> drop -> item -> starStone -> affixRandom` 命中廉贞星池；60 无 `starStone.affixRandom` 命中，也无可验证掉落链路。

# 丹元效果玩家视角复核

复核日期：2026-06-12

复核范围：`frontend/public/data/role_danyuan_effect.json` 当前导出的 30 个丹元家族，以及丹元效果页的说明区、品质表、等级成长表。

## 当前结论

- 30 个丹元家族均已存在玩家说明、关注项和等级/品质数值展示。
- 家族级 warning 为 0。
- 全局仍有 40 条 `DANYUAN_PLACEHOLDER_LEVEL_SKIPPED`，均为占位等级跳过警告，当前集中在青蛇丹元的高等级占位数据；这不是最终卡片缺列，但玩家看到“最高等级不连续”时可能需要解释。
- 百眼丹元需要展示异常值叠满后的韧性/闪避弱化成长：单次异常值是品质项，弱化固定下降值随丹元等级提升。

## 全局可能问题

1. **固定值与百分比拆分后，玩家可能只看等级表而忽略说明或品质表。**
   多个丹元的真实效果是“百分比系数 + 等级固定值”，等级表现在只显示固定值部分。玩家若只看表格，可能以为效果没有百分比系数。重点影响：青狮、白象、大鹏、白鹿、白狐。

2. **“充能”“触发机会”“冷却”容易被理解成同一个概念。**
   当前很多丹元有触发机会上限、触发后冷却、恢复间隔、初始机会等机制。玩家可能需要一眼看到“最多存几次、什么时候消耗、多久补回”。重点影响：青蛇、木仙、纳魔、百眼、青狮、白象、大鹏、白鹿。

3. **品质表与等级表承担不同职责，玩家需要习惯这个页面口径。**
   品质表放触发率、层数上限、系数、范围、持续时间等品质固定项；等级表只放同品质随等级成长的值。这个设计准确，但和游戏内“一个描述塞所有数值”的阅读习惯不同。

4. **攻略口径和配置口径不一致时，玩家可能质疑数值差异。**
   当前页面以配置和运行时代码为准，攻略只作辅助证据。典型例子是百眼先天炫目持续时间、部分无双/移速类描述。后续可在争议项旁增加“配置口径”标记。

5. **组合效果已有规则但缺少稳定数值导出。**
   青狮 + 白象的额外暴击/韧性组合效果已说明按较低品质与等级结算，但当前没有稳定导出组合数值表。玩家可能会继续追问具体暴击/韧性数值。

6. **召唤物、附加 buff、子弹命中类丹元的伤害来源仍有理解门槛。**
   青蛇、羊力、鱼涡、独角、九虫、火吼等效果经过召唤物、动作、子弹或附加 buff 链路。页面已翻译成玩家话，但玩家仍可能关心是否吃防御、属性抗性、命中次数、能否被规避。

7. **宽表在小屏上需要横向滚动。**
   落蛛、白鹿、青狮、白象、大鹏、白狐等存在多列或品质表。移动端玩家可能错过右侧列，需要后续视觉上强化横向滚动提示。

| 白鹿 | 三色丹药权重随当前血量变化，玩家可能以为随机概率固定；等级表只显示固定值，百分比在说明里。 |
| 白狐 | 友方死亡会先换算狂暴值，不是死一次固定一层；玩家也可能只关注加攻而忽略叠层后的降防成本。 |

## 后续可优化点

- 在等级表标题附近加一句短提示：等级表只放随等级成长的值，品质系数看上方品质表或说明。
- 对百眼这类“品质决定异常值、等级决定弱化固定值”的丹元，避免把异常值触发后的实际 buff 效果成长误判为空表。
- 对青狮、白象、大鹏、白狐这种“系数 + 固定值”的丹元，增加一条 Lv20 示例读法，降低玩家换算成本。
- 对组合效果缺数值的地方保留明确说明，不用占位数值，也不把攻略猜测写成配置事实。

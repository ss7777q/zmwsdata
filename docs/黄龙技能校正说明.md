帝雷破空旧口径把完整 630% 伤害除以 13 帧起手，误得约 14.54 攻转。应龙的神雷破空存在同一问题，已同步校正。

雷柱配置的伤害组件在 JSON 内未按时间排列。客户端按组件实际触发顺序递增伤害数组索引，因此必须先按 `t` 排序，再把 497.7% 配给起手、18.9% 配给持续六段与终段。直接按 JSON 顺序对应会把 497.7% 乘六，严重夸大倍率和固伤。

固伤基准采样排除 `effectOnly` 治疗卡以及每段均为 0/1 的占位值。不能把多个占位值加起来当成有效固伤。独立充能技能不构造等效 CD。

固伤倍率与固伤修正分开计算：`总固伤 / X`、`总固伤 / X / CD`。当前等级范围内，寰霆聚雷约 27X / 100%，追击约 30X / 120%，帝雷破空约 24X / 100%，四海龙朝约 30X / 142.86%。四海龙朝的较高修正来自配置中 30X 预算与 21 秒 CD，保留该真实差异，不人为压到 100%。低等级存在固值取整误差；50～60 级部分技能的固伤修正确有配置变化，按各等级原表保留。
